# EVA Catalog Frontend

React + TypeScript + Tailwind + React Query frontend for the vehicle template catalog.

## Run

```bash
cd apps/web
npm install
npm run dev
```

## Key UI features
- Virtualized card list for large datasets
- Expandable car cards with lazy-loaded modifications and logs
- Search + filters (brand, template type, status)
- Pagination with API caching via React Query
- Shadcn-style UI primitives under `src/components/ui`
